# The Night Foundation

**A not-for-profit that funds AI-assisted development on Midnight Network.**

---

## One Sentence

The Night Foundation gives builders with vision — but without deep technical expertise — the AI compute, tooling, and funding they need to ship privacy-first applications on Midnight, in exchange for a small protocol stake in what gets built.

---

## The Problem It Solves

Midnight Network has the best privacy infrastructure in the world. It has almost no applications.

The gap isn't talent. It's access. Building on a new chain with a new language (Compact), a new privacy model (ZK dual-ledger), and a non-obvious SDK requires months of ramp-up that most builders can't afford. The ones who persist ship eventually. Most give up before they start.

AI changes this completely — but only if the tooling, the prompts, and the compute are in the right hands.

The Night Foundation puts them there.

---

## What the Foundation Does

### 1. Maintains the Public Toolkit
`midnight-ai-kit` — open source, MIT licensed — is the AI developer toolkit for Midnight. Prompts, patterns, Compact examples, SDK fixes, deployment guides. The Foundation owns and maintains it. Every Midnight builder benefits, no membership required.

### 2. Runs the AI Builder Program
Qualified builders get:
- **AI compute credits** — Claude Code sessions funded by the Foundation
- **NIGHT/DUST credits** — deployment costs covered for preprod and mainnet
- **Technical support** — midnight-ai-kit patterns + async support from Foundation advisors

Qualification is on-chain. No application. No pitch deck. No grants committee.

### 3. Uses Night Score as the Quality Gate
Night Score is an objective, on-chain reputation built from real deployed activity:
- Contract deployed to preprod → +50 points
- ZK proof generated → +25 points
- Escrow completed → +50 points
- Token launched → +25 points

When a project's Night Score crosses **200 points**, it surfaces automatically for Foundation review. The code is the application.

### 4. Routes Finishing Bounties via Night Work
When a project hits threshold but needs completion:
- Foundation posts a bounty on Night Work (ZK-authenticated task marketplace)
- Real builders claim it via escrow on Night Markets
- Payment releases when code ships and passes review
- No identity required. No surveillance. Privacy by default.

## Ownership Model

Every app the Foundation helps finish is co-owned:

| Stakeholder | Share | Rationale |
|-------------|-------|-----------|
| Original creator | 50% | Vision, direction, the idea that mattered |
| Finishing builder | 30% | Execution, the last 20% that requires judgment |
| Night Foundation | 20% | Protocol revenue that funds the next round |

The Foundation's 20% is not extracted. It recirculates — into the next builder's compute credits, the next deployment costs, the next sprint.

---

## How the Foundation Stays Solvent

Three revenue streams, in order of reliability:

**1. Protocol revenue (20% of finished apps)**
Every app the Foundation helps ship generates ongoing protocol fees. As the ecosystem grows, this compounds. The Foundation holds a portfolio of real deployed contracts, not promises.

**2. Token treasury (NIGHT)**
The Foundation holds a NIGHT token grant from IOG/Midnight ecosystem fund. Token appreciation and staking yield provide baseline operating runway. Nothing is sold to fund operations — only yield is used.

**3. In-kind compute grants**
Anthropic provides Claude Code compute credits to qualifying Foundation builders. This is the ask that costs Anthropic almost nothing and produces case studies they actively want. One builder + Claude Code = 9 production apps is already that story.

---

## Governance

**Phase 1 (now → mainnet):**
Three-person steering committee. Decisions by simple majority. Night Score threshold for builder program is set by committee. Foundation holds NIGHT treasury in multisig.

**Phase 2 (post-mainnet):**
NIGHT token holders vote on threshold changes, treasury allocations >X NIGHT, and Foundation membership. On-chain governance via Night Hub. Steering committee retains operational veto on security issues only.

**What the Foundation never does:**
- Takes equity in builder projects beyond the 20% protocol stake
- Requires NDAs or exclusivity
- Funds proposals without deployed code
- Holds private fundraising rounds

The Night Foundation isn't a proposal for something to build.

One builder. No prior coding experience. One AI session with Claude Code and midnight-ai-kit as the system prompt.

- 9 privacy-first ZK applications on Midnight Network

- 7 SDK bugs documented and fixed for the entire ecosystem
- midnight-ai-kit: the toolkit every future Midnight builder will use

That builder is a 32-year-old farmer with no prior coding experience.

That is what the Foundation funds at scale.

## Why This Works

**For IOG:** Solves the ecosystem cold-start problem without IOG having to run a grants committee. Night Score is objective and manipulation-resistant. The Foundation funds builders who already proved they can ship.

**For Anthropic:** A deployed, production case study of Claude Code enabling non-technical builders to ship complex ZK applications on a cutting-edge blockchain. Replicable, documented, open source.

**For builders:** The gap between "I have a vision" and "I shipped a ZK contract on Midnight" collapses from months to days. The barrier becomes vision, not technical access.

**For the ecosystem:** Every Foundation-assisted app uses Night ID for identity, Night Score for reputation, Night Hub for discoverability, Night Work for builder coordination. The Foundation accelerates the network effect flywheel.
